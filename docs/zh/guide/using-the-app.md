# 使用应用

五个应用的通话界面都一样。手机上用触控操作，桌面端用鼠标和键盘。

## 手机：Android 和 iOS {#phones-android-and-ios}

<DemoMedia src="/media/call-ios.png" :width="320">
iPhone 竖屏进行 1:1 通话：对方的视频铺满屏幕，你自己的画面以小窗显示在角落，底部显示工具栏。
</DemoMedia>

- 只有你一个人时，摄像头画面铺满屏幕，并有一张卡片显示房间 ID 和复制按钮。对方加入后，你的画面会缩小成角落里的小窗。
- 点击画面可以显示或隐藏控件，几秒后控件会自动隐藏。
- 双击对方的画面，可以在 **fit**（显示完整画面，带黑边）和 **fill**（裁剪后铺满屏幕）之间切换。屏幕共享默认以 fit 显示。如果对方摄像头的方向和你的屏幕相反（比如竖着拿的手机对横着拿的手机），也默认用 fit。
- 你自己的小窗可以拖到任意一个角落。双击小窗或点击右上角的按钮，可以切换前后摄像头。
- 工具栏上有麦克风、摄像头、共享、聊天、**More** 和挂断按钮。More 里面是扬声器、特效、对方音频、对方视频、fit/fill 切换和切换摄像头。
- 两个应用都支持横屏，控件会避开摄像头开孔和导航栏。

## 桌面：Web、macOS 和 Windows {#desktop-web-macos-and-windows}

- 视频铺满整个窗口。移动鼠标即可显示控件，鼠标静止约四秒后自动隐藏。
- 工具栏按钮的提示中会显示对应的快捷键（见下文）。
- 麦克风、扬声器和摄像头可以在麦克风、摄像头按钮旁的菜单中选择。点击共享会打开一个选择器，实时显示各个屏幕和窗口的缩略图（浏览器会使用它自带的选择器）。
- 窗口较宽时，聊天以侧边栏形式打开。在 Web 端，宽度小于 1024 px 时聊天以底部面板形式打开；在手机浏览器上，More 会打开一个包含其余选项的面板。
- 你自己的画面可以拖到任意角落，双击对方的画面可以切换 fit 和 fill。
- 画中画按钮会让通话窗口浮在其他应用之上，并保留静音、摄像头、返回和挂断控件。在 Mac 上，最小化通话窗口时也会打开它。

### 键盘快捷键 {#keyboard-shortcuts}

| 按键 | 作用 |
| --- | --- |
| `M` | 开关麦克风 |
| `V` | 开关摄像头 |
| `C` | 显示或隐藏聊天 |
| `B` | 背景与特效 |
| `F` | fit 或 fill（仅 1:1 通话） |
| `P` | 画中画或悬浮窗口 |
| `Esc` | 关闭聊天或特效面板 |

在 Mac 上，这些快捷键也出现在 **Call** 菜单中，此外还有：⇧⌘S 共享屏幕，⌘O 共享视频文件，⇧⌘P 在多人通话中打开成员列表，⇧⌘E 离开通话。在聊天框中输入时，这些快捷键不会生效。

## 只影响你自己的操作 {#things-that-only-affect-you}

在 More 中把对方静音或隐藏对方的视频，只会改变你这台设备上的表现，对方不会收到通知。

当对方关闭摄像头，或者你隐藏了对方的视频时，你会看到对方头像后面是一张模糊处理过的最后一帧画面。对方说话时，头像周围的圆环会随之律动。

## 多人通话 {#group-calls}

<DemoMedia src="/media/group-web.png" :width="720">
Web 客户端中的多人通话，四到五个人来自不同平台：网格排列的画面小窗，带有标签（例如 "Android · 3f2a1c"），其中一个小窗带有绿色的说话圆环，一个显示麦克风关闭图标，还有一个因为摄像头关闭而显示头像。
</DemoMedia>

- 其他人以网格形式显示。每个小窗都标有对方的平台和一个短 ID，例如 `Android · 3f2a1c`；对方关闭麦克风时，小窗上会显示麦克风关闭图标。
- 绿色圆环标出正在说话的人。
- 点击计时器旁边的人数，可以打开房间内所有人的列表。你自己的标签排在第一位并高亮显示，方便你在其他设备上找到自己的小窗。
- 正在共享屏幕的人以 fit 显示，其他人铺满小窗。双击小窗（桌面端为双击鼠标）可以切换。
- 聊天消息经由 SFU 服务器转发，并显示每条消息的发送者。在 More 中静音音频或隐藏视频会作用于所有人，包括之后才加入的人。
- 在 Web 和 iOS 上，多人通话的小窗只显示头像，不显示模糊的最后一帧。在 iOS 上，系统画中画窗口只能在 1:1 通话中使用。
